About This Project

This site is a static DevOps blog built to demonstrate an end-to-end automated deployment pipeline: a website packaged into a Docker image, infrastructure provisioned on AWS with Terraform, and deployment automated with a Jenkins CI/CD pipeline.

Every push to the GitHub repository triggers Jenkins to build a new Docker image, push it to Docker Hub, apply the Terraform infrastructure, and roll out the updated container on an EC2 instance running Nginx.

Technology Stack

  • Frontend: HTML5, CSS3, JavaScript
  • Web Server: Nginx (Alpine)
  • Containerization: Docker & Docker Compose
  • Infrastructure as Code: Terraform (AWS Provider v5+)
  • Cloud Platform: AWS (VPC, EC2, Security Groups)
  • CI/CD: Jenkins Declarative Pipeline
  • Registry: Docker Hub
  • Source Control: Git & GitHub

Pipeline Overview

Developer → GitHub → Webhook → Jenkins → Docker Build → Docker Hub → Terraform Apply → EC2 Deployment → Health Check → Live Website
